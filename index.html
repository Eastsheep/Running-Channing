步頻趨勢

每分鐘步數（spm）。綠色帶是常見建議的 170–180，實際最佳值因身高和配速而異。

步幅趨勢

每一步前進的公尺數。速度＝步頻 × 步幅，配速變快時看是哪一個在進步。

平均心率趨勢

要搭配配速一起看：心率下降而配速不變，代表體能進步。

有氧效率 EF

速度（公尺／分鐘）÷ 平均心率，也就是每一次心跳能跑多遠。往上走代表有氧能力進步。

配速 × 心率

近 30 天更早

同樣心率下越高代表越快。藍點整體比灰點高，就是最近進步了。

步頻 × 配速

越右越快。點往右上延伸代表靠提高步頻加速；偏平則是靠加大步幅。

        還沒有 AI 分析

        1. 到 GitHub repo 的 Settings → Secrets and variables → Actions，新增 DEEPSEEK_API_KEY，值填你的 DeepSeek API 金鑰。
        2. 到 Actions →「同步 Garmin 跑步資料」→ Run workflow，跑完後重新打開 App。

        金鑰只存在 GitHub，不會出現在網頁裡。分析每次同步到新的跑步時自動更新。

        怎麼取得 Garmin 資料

        1. 自動同步：GitHub Actions 每天台灣時間 06:00 和 22:00 自動抓取並加密，打開 App 輸入資料密碼即可。設定方式見 repo 的 README。
        2. 手機匯出 CSV：Safari 開 connect.garmin.com 並切換為「要求桌面版網站」→ 活動 → 所有活動 → 篩選跑步 → 往下捲到要的日期 →「匯出 CSV」，再回來這裡匯入。
        3. 完整歷史：Garmin 帳戶「資料管理 → 匯出您的資料」，收到 zip 後匯入 DI_CONNECT/DI-Connect-Fitness/*_summarizedActivities.json。

        手動匯入的資料只存在這台裝置的瀏覽器裡。
